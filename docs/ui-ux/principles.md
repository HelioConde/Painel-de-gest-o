# Princípios de UI/UX

- Boa densidade de informação no desktop.
- Mobile adaptado, não apenas reduzido.
- Dados primeiro: cards para poucos elementos, listas e tabelas compactas para muitos.
- Cores de desempenho claras, com vermelho reservado para alertas ou resultado negativo.
- Acessibilidade, foco visível e contraste adequado.
- Loja selecionada sempre evidente.
- Responsividade como requisito desde o início.

Páginas iniciais planejadas: Dashboard, Eventos, Venda Diária, Venda Mensal, Fechamento Mensal e Perdas.

A futura página **Perdas** incluirá Visão Geral (vendas e perdas por setor) e Top Perdas (top 10 produtos por setor). Não há dados reais nesta fase.
